# ADR-0003：SQL 按实际有值字段生成列（稀疏列）
**状态**：已采纳（2026-10-13）

## 背景
早期按固定列清单输出 SQL，可选字段用连续 `NULL` 填充；多行插入冗长、难比对，且新增字段要改多处模板。

## 决定
主表、修改器、需求与 owner 关系按**实际有值字段**生成列清单；空的可选值不再占位；多行记录按列签名拆分 INSERT。必填字段仍由工程校验负责，规则与 modgen 契约、回归测试同步。

## 后果
- 输出随数据形状变化，diff 更小；同表不同列签名会拆成多条 INSERT。
- 回归基线需按语义（列/值）比对，不能假定固定列顺序。
