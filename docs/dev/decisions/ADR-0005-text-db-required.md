# ADR-0005：文本数据库是必配运行数据
**状态**：已采纳

## 背景
若文本库缺失时静默降级，生成物会缺文本，问题要到游戏里才暴露；文本库本身又是可随源码分发的大文件（`local_text_New.sqlite`）。

## 决定
把文本库定义为**必配运行数据**：未配置时中文预览显示「未知」、文本生成不完整，这是显式预期行为，而不是 bug。文本库随源码分发，但不进入任何打包安装流程；初始化脚本会探测并生成便携配置。

## 后果
- 新设备必须完成数据库配置（[install.md](../../user/install.md) 第一章），文档把它列为第一步。
- 错误在工具内立即可见；文本库可独立更新，不绑游戏版本。
