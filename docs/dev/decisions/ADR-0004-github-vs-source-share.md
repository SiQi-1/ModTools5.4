# ADR-0004：两个公开面——GitHub 仓库 vs 源码分享目录
**状态**：已采纳（2026-09-26）

## 背景
仓库里有本机工作区、历史产物、构建输出与本机设置；直接整目录打包会把它们和 Git 历史一起带出去，也无法说明来源。

## 决定
GitHub 仓库是唯一维护面。对外分享由 `tools/share_source.py` 从**已跟踪工作树**导出：只复制 `ROOT_FILES` + `SOURCE_DIRS` 内的可分发文件，拒绝产物/本机设置/虚拟环境，不覆盖已有目录；生成 `SOURCE_MANIFEST.json`（基准提交、是否有本地改动、UTC 时间、逐文件大小与 SHA-256）。CI 用同一检查兜底，只导出冒烟，不构建或上传二进制。

## 后果
- 分享内容可复现、可校验；分享目录不带 Git 历史。
- 新增文件必须先入 Git 索引才会被分享；白名单（`ROOT_FILES` / `REQUIRED`）需要随文档结构调整。
