# 文明6头像、图标与历史时刻

工具路径为 `python -m modgen.cli image`，不依赖某一家 AI。普通 PNG 合成仅依赖 Pillow；PSD 提取需要 `psd-tools`，区域样式渲染需要 `psd-tools[composite]>=1.20`。已有头像/历史时刻 PNG 底板、蒙版和配方可以直接复用。

先满足图像用途，再选择原作素材：文明图标是纯白 RGB + 透明背景；改良图标是白灰主体 + 透明背景；区域核心的**输入**是白色透明图，必须放入所选区域的 **Alpha 组内部**，继承渐变叠加、渐变描边、外发光，再与对应六边形底板合成。白色是输入蒙版要求，不是最终平涂颜色。头像需要经过构图的近景；历史时刻采用模板边缘与合适色调。不能直接把技能方图、整张立绘或彩色道具截图当作上述成品。

## 工作流程

1. 查看输入原图和模板。PSD 先用 `image inspect-psd` 读取图层编号、可见性、边界与特效；模板带有示例人物时先识别并排除示例层。
2. 用 `image extract-psd` 提取全画布蒙版、底板。PNG 配方路径相对于配方文件。具体命令和三类模板的已核实结构见 [模板与配方](references/templates.md)。
3. 对头像明确指定源图坐标中的 crop；对区域指定 PSD、Alpha 组和对应底板组编号，工具把白色核心插入 Alpha 组并隐藏旧样例。通过 `image render` 输出 PNG、散列报告和浅色/深色/棋盘格、多尺寸预览；区域额外输出保留原始样式的可编辑 PSD 副本。禁止以底板叠白图加简单描边替代 Alpha 组处理。
4. 实际查看预览，调整后重跑。`image check` 只检查像素，不能确认角色、人脸中心、设计优劣或游戏显示。至少检查 256 与 64/38/22 尺寸，避免缩小后眼睛、镂空、天线等消失。
5. 通过原有 .CIV 图片槽登记成品：`path` + `fit_mode: contain`，预制头像不要再次裁圆或加边框；历史时刻使用 `美术.data.moments_map`。由 ModTools 输出 DDS/TEX/XLP，继续工程校验与官方编译。

## 多模态与自动化边界

- 确定性工具能保证：尺寸、透明通道、白色/灰度像素、明确的裁切坐标、模板合成、输入散列与重复生成。
- 能看图的模型或人工负责：从立绘定位脸部、避开头发/饰物导致的视觉偏心，选择合适留白；辨认徽记、决定简化方式，检查区域核心在小尺寸下是否仍可读。
- 无看图能力的 AI 可以复用已经验收的配方坐标并生成候选；不得以 Alpha 包围盒、非透明像素质心、自动人脸检测或脚本返回成功，声称头像已居中或成品已验收。缺少已确认坐标时交付候选预览并明确需要看图复核。
- 纯白转换仅适合已有透明轮廓，或显式指定的黑底白图。复杂彩色图片须先由有视觉能力的模型/人工抠图、简化或重新绘制；工具不承诺自动理解语义轮廓。
- PSD 的 pixels 模式读取原始像素，不渲染描边等特效；composite 模式会重算可见图层，但不承诺复现所有 Photoshop 智能对象、调整层、混合与图层样式。检查对照后，可用 Photoshop/兼容编辑器导出的 PNG 替换底板。
- 区域 PNG 按 PSD 参数处理渐变、内部渐变描边、外发光及底板内发光；发光核、渐变平滑度/抖动和色彩管理仍有原生 Photoshop 差异，报告必须保留这些边界。已知不支持的样式报错，不能静默省略。要求像素级一致时，以工具生成的可编辑 PSD 在 Photoshop 中原生导出；不能声称脚本图已通过 Photoshop 对照。

## 资源边界

用户已确认这套社区 PSD 可纳入 Git 和分享，原件现位于 [assets/templates](assets/templates/manifest.json)：`district.psd`、`leader.psd`、`moments/*.psd` 和原使用说明。manifest 记录原名、大小、SHA-256 与用户提供的分享依据；作者暂未确认，不虚构署名或将模板改称本项目原创。源码分享工具会携带这些资源，无需用户再次提供本机绝对路径。

单个 Mod 的立绘、裁切稿、成品、构建包仍保存在自己的资源目录或 `modgen_work/`。迁移时携带已获授权的源图和相对路径配方，保留来源记录。
