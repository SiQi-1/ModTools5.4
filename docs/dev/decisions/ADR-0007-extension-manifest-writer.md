# ADR-0007：项目级扩展清单只有一个写入者
**状态**：已采纳（2026-09-23）

## 背景
项目级扩展 = 顶层 `.CIV.extensions`（version 1，记录源码根与角色/作用域/阶段/特性/依赖）+ 工程旁源码目录。GUI 保存、CLI 与 AI 动作都可能改写它，容易丢清单，或用输出目录当源码回退，造成「生成成功但源码丢失」。

## 决定
Qt-free 的 `project/extensions.py` 独占清单校验、源码写入与动作规划；GUI 保存只保留清单、绝不重写；CLI `extension` 与 AI `extension` 共用它。缺失源码、冲突与无效依赖阻断生成，不回退输出文件。

## 后果
- 扩展状态单一来源，GUI/CLI/AI 行为一致，预览与生成能检测缺失/冲突。
- 扩展工程不能靠输出文件恢复；GUI 侧代码须遵守「只读清单」约定。
