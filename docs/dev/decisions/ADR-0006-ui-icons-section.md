# ADR-0006：「UI图标」是非实体分节、不进导航树
**状态**：已采纳（2026-09-19）

## 背景
自定义 UI 图标（新闻分类、单位动作、追踪器等）与任何游戏实体无关。若做成工作区树节点，会与「美术」重复，并让「一节=一类实体」的模型出现例外入口。

## 决定
`.CIV` 保留独立的「UI图标」分节（列表存储），由**美术页专属编辑区**管理；工作区树跳过 `CIV_UI_ICON_SECTIONS`，不单列节点。校验在 Qt-free 的 `project/ui_icons.py`，GUI 生成前检查与 `modgen validate` 共用；产出只有 `Icons.xml` 与 IMG/Textures，命名空间冲突报 ERROR。

## 后果
- 数据可保存/往返，但导航树不出现新入口；旧工程缺该节自动补空。
- 新增图标类型只改一处校验；不要为它添加树节点或第二个编辑入口。
